# Report completion notes

Use the companion Word report as your writing guide. Before submission:

1. Enter the exact Python version from your terminal.
2. Add the URL of your own GitHub repository.
3. Run Task 10 and paste your measured totals and timings into its results table.
4. Add a screenshot after each task's execution; use the evidence folder for that task.
5. Confirm faculty access to the repository if it is private.
6. Rerun both automated test suites after the last code change.
7. Make the final commit and verify `git status` is clean.

The report's illustrative arithmetic results are deterministic. Benchmark timings are intentionally left for your machine because they depend on hardware, interpreter build and system load.
